# Privacy

## Local-first principle

- Raw footage, full-resolution exports, and project workspaces stay on the local editing computer by default.
- Only metadata, transcripts, and low-resolution proxies leave the machine when a cloud AI or transcription provider is configured.
- Settings page lists exactly what data is shared and with which provider.

## Consent and rights

- Project-level notes can record rights/consent information.
- The system does not fabricate speech, claims, or endorsements.
- Privacy masking / face blurring is available as an approved operation.
